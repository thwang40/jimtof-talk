# 展會會話（JIMTOF 2026 出差日語）
Personal study PWA (Japanese for a JIMTOF 2026 trip). Same design/UX as 撿角日語 (nh-study): BAOJE catalogue colours, listen-first book-style dialogues,
key patterns in red bold, 🗣 開口練習 role-play (scene only → 💡 hint on request → original + 2 alternatives), search with 聽力模式, review list, offline download.
Audio: VOICEVOX (玄野武宏 / No.7 / 冥鳴ひまり / 雀松朱司); `_s` files are native 0.7x.
Content: `tools/jt_content.py` (phrases, dialogues), `tools/jt_rp.py` (role-play hints + alternatives, key patterns, partner names).
Rebuild: `python3 tools/build.py && python3 tools/gen.py audio` (needs local VOICEVOX engine; `tools/check.py` / `tools/check_rp.py` compare readings). Bump cache names in sw.js and AUDIO_CACHE in app.js on audio changes.

## 🗾 日本行每日（出差期間每天一個單元）
Content: `tools/jt_daily.py` — `DAYS` list (one dict per day: scenes with photos / words in the photo / tip / phrases tagged with the 《文化初級日本語》 lesson `L` / refs to pre-trip sentences, dialogues, `must5`), `RP_D` (role-play hints + 2 alternatives for every dialogue line), `PAT_D`, `ROFIX` (romaji fixes).
**Standard for every day — 📷 照片裡的日文 (words):** keep every Japanese word/sign seen in the photos as `(ja, kana, zh, [ex×3])`; each word has **exactly 3 example sentences** `(ja, kana, zh, L)` using only 《文化初級日本語》 第 1～12 課 grammar (tag `L` with the lesson pattern, e.g. `第4課・〜はどこですか`; anything outside L1–12 must say `課外…／簡單說法：…`), practical for the trip / JIMTOF. build.py asserts 3 examples per word and makes audio for every word (voice `f`) and example (voice `me`), 1x + `_s` 0.7x. UI is listening-first: word list and each word's examples (collapsed `<details>` under the word) are separate `data-blk` blocks with ▶ play + 👁; tap a row 日文 → 中文 → hide; 🙋/📝 review and 🔍 search work for words (`單字`) and examples (`例句`).
**Word thumbnails (📷 小截圖, standard for every day):** in `tools/jt_daily.py` → `CROPS_D['<day id>']` give `crops` = `{word ja: (photo, (x0, y0, x1, y1)[, 'fallback'])}` (box in 0–1 fractions of the photo, text only — padding is added automatically; use `'fallback'` + a related area when the word is not in any photo, shown as 「相關畫面」), `orig` = `{photo: original file path}` (crop from the sharp original; originals are never committed — falls back to `img/<id>/<photo>.webp`), and `blur` = `{photo: [boxes]}` for names / barcodes / ticket & seat numbers / room numbers (always pixelated before cropping). `python3 tools/crops.py` writes `img/<id>/w/<word id>.webp` (long edge ≤480px, WebP q≈70, ≤30KB; only missing ones, `--force` to redo). Crops show the surrounding text: the box is widened ~2–3× (left/right +0.75 box width, top/bottom +1.6 box height, vertical text gets neighbouring columns) and the target word is outlined in orange with a light yellow fill (add `'nomark'` to skip the outline). The URL carries `?v=<hash>` so changed crops bypass caches. build.py adds `th` to the word; the row shows it on the right (390px: under the icon row; blurred while the text is hidden, clear after reveal, tap to enlarge) and sw.js caches it with the photos.
To add a day: append a dict to `DAYS` (id `dMMDD`), put photos in `img/<id>/` (long edge ≤1280px, WebP q75, ≤200KB each, never originals; blur names/barcodes), then
`python3 tools/crops.py && python3 tools/build.py && python3 tools/check.py && python3 tools/check_rp.py && python3 tools/gen.py audio` (only new clips are generated), bump `SHELL`/`AUDIO` in sw.js (+ migration) and `AUDIO_CACHE` in app.js.
UI: home 「🗾 日本行每日」 section + sidebar group; day page tab 📷 照片教學 (`#/c/<id>/g`), 📣 句子, 🎧 對話; 今日 5 句必背 跟讀 at `#/sh/<id>-m5`.
